EcoGuia - Atividade Somativa 1
================================

Este projeto foi criado com HTML, CSS e JavaScript puro, sem frameworks.

Arquivos principais exigidos:
- index.html: página inicial
- form.html: formulário com validação de todos os campos
- formAction.html: página que recebe dados por GET e lê os parâmetros com JavaScript
- about.html: página informativa sobre o projeto

Pastas:
- css/style.css
- js/main.js
- js/form.js
- js/action.js
- images/

Como abrir:
1. Extraia o arquivo .ZIP.
2. Abra a pasta ecoguia_site.
3. Clique em index.html ou abra a pasta no VS Code e use Live Server, se tiver.
4. Antes de entregar, troque "Seu Nome" em about.html pelo seu nome.
