Sobre o projeto

Apresentação do trabalho

Este site foi desenvolvido para a Atividade Somativa 1, com tratamento exclusivo de front-end. O projeto utiliza apenas HTML, CSS e JavaScript, sem frameworks, bibliotecas externas ou plataformas de código.

Autor(a): Seu Nome
Tema: Sustentabilidade e hábitos conscientes
Objetivo: demonstrar estruturação HTML, estilização CSS, navegação uniforme e interação com JavaScript.

Tecnologias

O que foi aplicado?

HTML

Estrutura

Foram usados elementos semânticos como header, nav, main, section, article, form, fieldset e footer. As páginas principais são index.html, form.html, formAction.html e about.html.

CSS

Apresentação

O arquivo css/style.css centraliza as regras visuais, com classes reutilizáveis, responsividade, botões, cards, formulário e tema escuro.

JS

Interação

Os arquivos JavaScript controlam menu responsivo, alternância de tema, modal, validação de campos e leitura de parâmetros enviados por GET.
